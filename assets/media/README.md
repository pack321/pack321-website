# Pack 321 shared media library

`manifest.json` is the storefront's single source of truth for approved imagery. It references canonical Pack 321 files already in `assets/images` and `assets/optimized`; files are not duplicated here.

Logical collections mirror the approved architecture: `heroes`, `campaigns`, `events`, `products`, `leaders`, `branding`, and `placeholders`. ScoutHQ can later replace or extend manifest entries while preserving consent and archive metadata.
