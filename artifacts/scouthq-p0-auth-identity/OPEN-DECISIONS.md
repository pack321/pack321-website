# Open Decisions

Package 1 has no blocking authentication, identity, onboarding, approval, or authorization defects.

Deferred to Package 2 under separate approval:

1. Permanent Parent and Leadership interface and vertical slices.
2. Permanent approval cards, request details, Needs Information, and Deny workflows.
3. My Day approval widgets and broader Pack-wide application routes.
4. Canonical dependent/Scout linkage to the future People model.

The temporary staging-shell approval control exists only to validate Package 1 backend behavior and must not be treated as the permanent interface.
