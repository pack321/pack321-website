# Role Matrix

| Role | Own household | Pack people | Access approval | Finance/reports | Campaign admin |
|---|---:|---:|---:|---:|---:|
| Parent / Guardian | Yes | No | No | No | No |
| Committee Chair | No implicit household | Yes | Yes | No | No |
| Cubmaster | No implicit household | Yes | No | No | No |
| Treasurer | No implicit household | No | No | Yes | No |
| Campaign Administrator | No implicit household | No | No | No | Yes |

Multiple active membership roles combine permissions. Suspended/deactivated memberships receive none.
