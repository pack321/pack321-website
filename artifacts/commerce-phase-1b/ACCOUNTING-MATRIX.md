# Accounting Matrix

| Field | $50 merchandise example |
|---|---:|
| Merchandise subtotal | 5000 |
| Online convenience fee | 300 |
| Tax | 0 |
| Gross charged by Stripe | 5300 |
| Stripe fee | Actual balance transaction fee after payment |
| Refund total | Sum of successful refund ledger rows |
| Net | gross - Stripe fee - refunds |
| Scout sales credit | Eligible merchandise only; excludes fee, tax, Stripe fee, and donation lines |

The convenience-fee refund treatment remains intentionally unset pending approval.
